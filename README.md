# 주말 어디 가지

날짜를 고르면 그날 아이와 갈 수 있는 곳을 지역별로 보여주는 개인용 웹페이지.
서울에서 차로 2시간(약 150km) 반경까지. 지인들과 링크로 나눠 쓸 목적.

## 파일

```
index.html          화면 (data.json을 읽는다)
collect.js          자료 수집기 — 거르는 규칙이 전부 여기 있다
data.json           수집 결과 (2,445건)
preview.html        collect + index를 합친 미리보기 (자료가 페이지에 박혀 있음)
keys.json           인증키 (.gitignore에 있음, 절대 커밋 금지)
keys.example.json   키 넣는 자리 견본
```

미리보기 만드는 법 — `index.html`의 `<script>` 앞에 `window.__DATA__`로 data.json을 끼워 넣는다.

## 거르는 규칙 (collect.js, 사용자와 하나씩 합의한 것)

서울 예약을 468건으로 줄인 규칙들. 임의로 되돌리지 말 것.

- **분야**: 체육시설(테니스·풋살 대관)·공간시설(강당·촬영장) 통째 제외
- **상태**: 접수중·안내중만. 예약마감·접수종료·일시중지 제외
- **단체 전용** 제외. 단 "개인/단체", "단체는 전화문의", 대상칸에 "가족"이 있으면 남긴다
  ("용산가족공원"처럼 이름에 든 '가족'은 세지 않으려고 가족은 **대상 칸에서만** 본다)
- **성인 전용** 제외. 단 "성인, 청소년"이나 "성인(보호자), 어린이"처럼 아이가 끼면 남긴다
- **외국인 전용**, **난임·임산부·태교·산모** 제외
- **서울형 키즈카페** 제외 (지점마다 줄이 생겨 목록을 덮었다, 133건)
- **팀·학급 단위** 제외 (3인 이상 1팀 / 학급 / 1기관 / 4명 이상 필요).
  단 "2인 1팀"(부모+아이)과 "최대 N인"(상한)은 남긴다

### TourAPI 분류 걸러내기

관광공사 자료는 분류가 넓어서 통째로 받으면 술집·모텔·동네 골목까지 들어온다.
**소분류(cat3) 흰 목록에 든 것만 통과**시키고 나머지는 전부 버린다.

**관광지(contentTypeId=12) — 무조건 남기는 분류**

```
자연생태관광지  자연휴양림  수목원  도립공원
고궁  민속마을  테마공원  유람선  전통체험  식음료
계곡  해수욕장  호수  폭포
```

**이름을 보고 남기는 분류** — `농.산.어촌 체험`·`이색체험` 둘은 관광공사 쪽 분류가
엉성해 `강남`·`경리단길`·`족발골목` 같은 동네 이름이 잔뜩 섞여 있다. 두 조건을 **모두**
만족할 때만 남긴다.

1. 제목에 체험거리로 읽히는 낱말이 있다 (체험·박물·농장·공방·수목·아쿠아·워터 등 25개)
2. 제목이 `마을`이나 `거리`로 끝나지 않는다 (서래마을·연남동 공방거리를 뺀다)

**문화시설(contentTypeId=14) — 남기는 것은 넷뿐**

```
박물관  기념관  전시관  미술관/화랑
```

- `미술관/화랑` 중 이름에 **갤러리**가 든 것은 뺀다. 상업 화랑이라 아이와 갈 곳이 아니다
  (간송미술관은 남고 갤러리 라메르는 빠진다)
- **공연장·도서관·문화원·문화전수시설·컨벤션센터·대형서점·영화관·학교·외국문화원**은
  사용자 지시로 통째 제외
- **레포츠(contentTypeId=28)는 통째로 안 받는다** — 열어 보니 캠핑장·낚시터가 대부분이다
- **공원 394건, 기타 자연 78건도 제외** — 동네 근린공원·이름뿐인 지형이라 목록만 덮는다

축제는 `areaBasedList2`가 아니라 **`searchFestival2`**로 받는다. 앞의 것은 행사 날짜를
주지 않는데, 날짜가 이 앱의 전부라서 쓸 수가 없다.

받는 지역(areaCode)은 서울·경기·인천·강원·충북·충남·세종·대전 여덟 곳. 나머지는 반경 밖이다.

### 중복 제거

같은 곳이 여러 자료원에 들어 있다. 이름에서 **괄호와 그 안의 글자를 지우고 → 공백·`·`·`-`·`_`·
`,`·`.`을 지우고 → 소문자로** 바꿔 비교해, 겹치면 하나만 남긴다. 이번엔 236건이 빠졌다.

우선순위는 **TourAPI → 표준데이터(박물관·축제·공연행사) → 전국관광지정보**.
TourAPI를 앞에 둔 것은 사진이 붙어 있어 카드가 잘 보이기 때문이다.

**서울 예약 자료는 중복 제거 대상이 아니다.** 같은 장소에서 여는 여러 프로그램이라
이름이 겹치는 게 정상이고, 지우면 프로그램이 통째로 사라진다.

### 긴 글 자르기

전국관광지정보의 소개글(`trrsrtIntrcn`)은 몇백 자짜리라 **120자에서 자른다**.
안 자르면 data.json이 몇 배로 불어난다.

## 나이 읽기 (핵심)

대상 문구를 **자르지 않고 통째로** 읽어 나이 범위를 뽑는다. 495건 100% 해석됨.

```
"유아(만5세이상), 초등학생"             → 5~12세
"가족(초등학교 4~6학년 어린이 동반 가족)" → 10~12세
"성인, 청소년, 초등학생(4학년이상)"      → 10~99세
```

방식: 괄호를 지키며 쉼표로 나눔 → 조각마다 낱말로 기본 범위(유아=3~6) → 괄호 안 나이·학년으로 **교집합**.
카드에는 대상 **원문 그대로** 보여준다. 잘라 쓰면 안 된다(사용자 지시).

## 화면

- 탭 2개: 찾기 / 설정
- **찾기**: 직접 그린 달력(일=빨강, 토=파랑) + 나이 묶음 체크박스(유아·초등학생 기본 켜짐)
- 결과: **섹션(행사·축제 / 예약해야 하는 곳 / 아무 때나 가도 되는 곳 / 직접 확인)** 안에서
  다시 **지역별로 접기·펼치기**. 섹션마다 가장 가까운 지역 하나만 펴짐
- 카드: 사진(152px, 왼쪽) / 1줄 지역·장소 / 2줄 대상 / 제목 / 시간 / 배지 / 자세히→
- 글자 크기는 카드 안 전부 16px로 통일
- 정렬은 설정의 출발지 기준 **거리순**이되 카드에 km은 표시하지 않는다
- 상시 시설은 가까운 **500곳**까지만 (`index.html`의 `placeLeft`).
  40이던 것을 늘렸다 — 자료가 614건에서 1,719건이 되면서 40곳이 서울 8km 안에서
  다 차버려 경기도가 3곳밖에 안 보였다. 500이면 30km 안, 경기 18개 시군까지 들어온다

## 지역 이름 통일

서울 예약은 `도봉구`, 표준데이터는 주소에서 뽑아 `서울특별시 도봉구`가 되어 같은 곳이 두 묶음으로
갈렸다. `collect.js`의 `areaOf()`에서 맞춘다 — 서울은 구 이름만, 나머지는 `경기 고양시`처럼 줄인다.

TourAPI는 주소 칸 이름이 달라서(`addr1`), 주소 문자열만 받는 `areaOfAddr()`을 속살로 빼고
`areaOf()`가 그것을 부르게 했다. 규칙은 하나뿐이라 두 자료가 항상 같은 이름으로 나온다.

## 안 되는 것 (확인 완료, 다시 찾지 말 것)

- **모집정원·잔여석**: 어느 API에도 없다. 서울은 상세설명 글 속에 9%만 있고 그나마 "회차당 1기관"
  같은 형태다. 공연행사 `seatNumber`는 공연장 좌석수지 남은 자리가 아니다
- **숲나들e 실시간 빈자리**: 로그인이 필요해 배포판에 못 넣는다. 산림청 공개 API는
  2023~2024년 과거 통계라 쓸 수 없다. 쓰려면 k-skill(`foresttrip-vacancy`) + 파이썬·Playwright,
  사장님 PC 전용
- **로그인 벽이 있는 지자체 예약처**(예: 남양주시 체험관광): 자동 수집 불가.
  `collect.js`의 `MANUAL` 목록에 링크만 넣어 "직접 확인" 칸으로 보여준다. 발견하면 여기 추가
