## 파일

```
index.html          화면 (data.json을 읽는다)
collect.js          자료 수집기 — 거르는 규칙이 전부 여기 있다
data.json           수집 결과 (2,478건 + 휴양림 96곳)
preview.html        collect + index를 합친 미리보기 (자료가 페이지에 박혀 있음)

keys.example.json   키 넣는 자리 견본
```

미리보기 만드는 법 — `index.html`의 `<script>` 앞에 `window.__DATA__`로 data.json을 끼워 넣는다.

### TourAPI 분류 걸러내기

관광공사 자료는 분류가 넓어서 통째로 받으면 술집·모텔·동네 골목까지 들어온다.
**소분류(cat3) 흰 목록에 든 것만 통과**시키고 나머지는 전부 버린다.

**관광지(contentTypeId=12) — 무조건 남기는 분류**

```
자연생태관광지  자연휴양림  수목원  도립공원
고궁  민속마을  테마공원  유람선  전통체험  식음료
계곡  해수욕장  호수  폭포
```

**이름을 보고 남기는 분류** — `농.산.어촌 체험`·`이색체험` 둘은 관광공사 쪽 분류가
엉성해 `강남`·`경리단길`·`족발골목` 같은 동네 이름이 잔뜩 섞여 있다. 두 조건을 **모두**
만족할 때만 남긴다.

1. 제목에 체험거리로 읽히는 낱말이 있다 (체험·박물·농장·공방·수목·아쿠아·워터 등 25개)
2. 제목이 `마을`이나 `거리`로 끝나지 않는다 (서래마을·연남동 공방거리를 뺀다)

**문화시설(contentTypeId=14) — 남기는 것은 넷뿐**

```
박물관  기념관  전시관  미술관/화랑
```

- `미술관/화랑` 중 이름에 **갤러리**가 든 것은 뺀다. 상업 화랑이라 아이와 갈 곳이 아니다
  (간송미술관은 남고 갤러리 라메르는 빠진다)
- **공연장·도서관·문화원·문화전수시설·컨벤션센터·대형서점·영화관·학교·외국문화원**은
  사용자 지시로 통째 제외
- **레포츠(contentTypeId=28)는 통째로 안 받는다** — 열어 보니 캠핑장·낚시터가 대부분이다
- **공원 394건, 기타 자연 78건도 제외** — 동네 근린공원·이름뿐인 지형이라 목록만 덮는다

축제는 `areaBasedList2`가 아니라 **`searchFestival2`**로 받는다. 앞의 것은 행사 날짜를
주지 않는데, 날짜가 이 앱의 전부라서 쓸 수가 없다.

받는 지역(areaCode)은 서울·경기·인천·강원·충북·충남·세종·대전 여덟 곳. 나머지는 반경 밖이다.

### 자연휴양림에 숲나들e 링크 붙이기

휴양림 카드에는 `지도 →`밖에 없어서, 예약 정보를 보려면 숲나들e에 들어가 이름으로
다시 찾아야 했다. 이제 이름이 맞는 휴양림에는 `자세히 →`가 붙어 소개 페이지로 바로 간다.

```
https://www.foresttrip.go.kr/indvz/main.do?hmpgId=<ID>
```

**목록을 어디서 받았나** — 숲나들e 휴양림 검색 목록을 세 단계로 받았다. 세션 쿠키와
CSRF 토큰이 있어야 해서 주소만 안다고 바로 되지는 않는다.

```bash
# 1) 검색 화면을 쿠키와 함께 받아 CSRF 토큰을 뽑는다
curl -s -c ck.txt -A "Mozilla/5.0" \
  "https://www.foresttrip.go.kr/pot/is/fs/selectFcltSrchView.do?hmpgId=FRIP&menuId=002001" -o ft.html
TOKEN=$(grep -oE '_csrf=[0-9a-f-]{36}' ft.html | head -1 | cut -d= -f2)

# 2) 같은 세션으로 권역별 목록을 받는다 (GET, X-Ajax-call 헤더가 필요하다)
curl -s -b ck.txt -A "Mozilla/5.0" -H "X-Ajax-call: true" \
  "https://www.foresttrip.go.kr/rep/or/selectInsttListForSearch.do?_csrf=$TOKEN&srchSido=1"
```

- 권역 코드는 `/rep/or/selectSiDoList.do` 로 얻는다 — **1** 서울·인천·경기, **2** 강원,
  **3** 충북, **4** 대전·충남 (5 전북, 6 전남광주 등은 반경 밖이라 안 받았다)
- `srchSido`를 비우면 빈 목록이 온다. 반드시 권역을 지정해야 한다
- 응답 `insttList[]`에서 쓸 것은 `insttNm`(이름)과 `insttId`(ID) 둘뿐이다.
  나머지 80여 개 칸(`cvncFcl` 편의시설 등)은 **목록 조회에서는 전부 비어 있다**

네 권역을 합쳐 96곳. 받은 날은 2026-08-13. 결과 96줄을 `collect.js`의 `FOREST` 상수에 박아뒀다.
한 줄은 `[권역, 시군, 이름, ID]` — 권역·시군은 화면의 휴양림 탭에서 쓰려고 넣었고,
`data.json`의 `forests` 키로 그대로 나간다. 링크 붙이기(`forestNorm`)는 예전처럼 **이름만** 본다.
**수집기에서 매번 부르지 않는다** — CSRF 토큰과 세션이 필요해 수집기가 복잡해지는 데다,
휴양림 목록 자체는 자주 바뀌지 않는다. 갱신이 필요하면 위 주소를 브라우저에서 다시 불러
받은 목록을 `FOREST`에 덮어쓰면 된다.

**이름 맞추는 규칙** (`forestNorm`) — 양쪽 이름을 같은 꼴로 만들어 비교한다.

- 괄호와 그 안의 글자를 지운다 (`(가평군)강씨봉자연휴양림` → `강씨봉자연휴양림`)
- 공백·`·`·`-`·`_`·`,`·`.`을 지운다
- 맨 앞의 `국립`·`도립`·`시립`·`군립`·`공립`을 지운다 (`국립 산음자연휴양림` → `산음자연휴양림`)
- `자연휴양림`을 `휴양림`으로 통일한다

붙이는 대상은 **TourAPI 관광지(contentTypeId=12)** 중 cat3가 자연휴양림(`A01010600`)이거나
제목에 `휴양림`이 든 것뿐이다. 이미 `url`이 있으면 덮어쓰지 않는다.

**산림욕장·도시자연공원에는 안 붙는다.** 숲나들e는 숙박 예약을 받는 휴양림 통합예약처라
`구름산 산림욕장`·`문수산산림욕장`·`잣향기푸른숲` 같은 곳은 애초에 등록되어 있지 않다.
없는 것을 억지로 검색 링크로 만들지 않는다 — 지도 링크가 그대로 남는다.

결과 — 휴양림성 항목 67건 중 **33건**에 링크가 붙었다. 표본 7건을 실제로 열어
`<title>`에 그 휴양림 이름이 들어 있는 것을 확인했다(구석구석 때처럼 죽은 링크가
아닌지 확인한 것이다).

⚠️ `용현자연휴양림`·`장태산휴양림` 2건은 이름은 맞는데 링크가 없다. **전국관광지정보**
쪽에서 들어온 항목이라 TourAPI 관광지 매핑을 안 거치기 때문이다. 필요하면 그때 넓히면 된다.

### 중복 제거

같은 곳이 여러 자료원에 들어 있다. 이름에서 **괄호와 그 안의 글자를 지우고 → 공백·`·`·`-`·`_`·
`,`·`.`을 지우고 → 소문자로** 바꿔 비교해, 겹치면 하나만 남긴다. 이번엔 236건이 빠졌다.

우선순위는 **TourAPI → 표준데이터(박물관·축제·공연행사) → 전국관광지정보**.
TourAPI를 앞에 둔 것은 사진이 붙어 있어 카드가 잘 보이기 때문이다.

**서울 예약 자료는 중복 제거 대상이 아니다.** 같은 장소에서 여는 여러 프로그램이라
이름이 겹치는 게 정상이고, 지우면 프로그램이 통째로 사라진다.

### 긴 글 자르기

전국관광지정보의 소개글(`trrsrtIntrcn`)은 몇백 자짜리라 **120자에서 자른다**.
안 자르면 data.json이 몇 배로 불어난다.

## 경기도 시군 예약

"예약해야 하는 곳" 칸은 오랫동안 서울시 자료뿐이라 경기도가 0건이었다. 그 첫 구멍을
**남양주시 체험·견학**으로 메웠고, 두 번째로 **김포시 견학·체험**을 붙였다.
API가 아니라 **서버가 그려주는 HTML을 읽는다.** 둘 다 로그인이 필요 없고 UTF-8이다.

⚠️ **시군마다 화면 구조가 다르다.** 남양주는 표(`<tr>`/`<td>`), 김포는 목록(`<li>`)이라
자르는 방법부터 다르다. 아래에 각각 따로 적었다.

### 남양주시 (첫 사례)

```
목록  https://www.nyj.go.kr/reserve/selectUserExprnTourBasicInfoList.do?key=3383&pageUnit=100&pageIndex=<쪽>
상세  https://www.nyj.go.kr/reserve/selectUserExprnTourBasicInfoView.do?key=3383&searchTourKey=..&searchExprnKey=..
```

- 전체 104건. `pageUnit=100`이면 2쪽이면 다 받는다. 코드는 넉넉히 **4쪽까지** 돌되
  항목이 안 나오면 멈춘다
- 상세 링크는 목록의 제목 칸에 `href="./selectUserExprnTourBasicInfoView.do?…"` 로 들어 있다.
  앞에 `https://www.nyj.go.kr/reserve/`를 붙이고 `&amp;`를 `&`로 되돌린다

**목록 표의 칸 순서** (`<tr>` 안 `<td>`, 7칸이 안 되는 줄은 머리글이라 건너뛴다)

| 칸 | 내용 | 예 |
|---|---|---|
| 0 | 번호 | `104` |
| 1 | **기관** (좌표를 여기서 찾는다) | `정약용유적지` |
| 2 | **카테고리** → `sub` | `체험견학` `교육` `숲교육` `목공예` `산림치유` `놀이숲` `체험` `관람` |
| 3 | **제목** (상세 링크가 이 칸에 있다) | `[초등학생 포함 가족] 정약용과학창의학교…` |
| 4 | **접수기간** → `rcptStart` ~ `rcptEnd` | `2026-08-17 09:00 ~ 2026-08-28 23:59` |
| 5 | 접수방법 (안 쓴다) | `온라인` |
| 6 | **접수상태** | `접수중` `접수대기` `접수마감` |

**⚠️ 접수상태가 `접수중`인 것만 받는다.** 104건 중 9건이다. 서울 예약이 `접수중·안내중`만
받는 것과 같은 기준으로, 나머지 94건(대부분 접수마감)은 지금 신청할 수 없으니 버린다.
**돌릴 때마다 건수가 달라지는 게 정상이다** — 서울 예약과 같다.

**상세에서 더 받는 것** — 접수중인 것만 연다(10건 안팎이라 부담 없다).
상세는 `<th>항목</th><td>값</td>` 쌍이라 항목 이름으로 찾는다(`nyjField()`).

| 상세 항목 | 쓸 곳 |
|---|---|
| 모집대상 | `target` (**원문 그대로**) + `ageRange()`로 `ageMin`/`ageMax` |
| 이용요금 | `fee` |
| 장소 | `place` (없으면 목록의 기관 이름으로 채운다) |
| 문의전화 | `tel` |
| 소요시간 | `time` |

상세를 못 받아도 목록 정보만으로 넣고 콘솔에 한 줄 남긴다. 시청 페이지 하나 때문에
수집 전체가 죽으면 안 된다.

**좌표를 코드에 박은 사정** — 이 페이지는 위경도를 전혀 주지 않는다. 기관 이름만 있어서
관광공사 API로 찾은 값을 `NYJ_ORG_XY`에 표로 박았다.

```
정약용유적지      37.5166, 127.2993
물맑음수목원      37.7058, 127.2956
남양주시립박물관   37.5464, 127.2444
```

표에 없는 기관은 **남양주시청**(`37.6360, 127.2165`)으로 간다. `유아숲체험원`·`남양주 궁집`·
`REMEMBER 1910`·`그린학습원`은 관광공사에 등록이 없어 위치를 확인할 수 없었다. 지도 링크는
제목으로도 검색되니 시청 좌표라도 카드가 엉뚱한 지역으로 새지는 않는다.

**나오는 스키마** — 서울 예약과 똑같이 맞췄다. `kind:"reserve"`면 화면이 알아서
"예약해야 하는 곳"에 넣으므로 `index.html`은 손댈 일이 없다.

```
kind "reserve" / group "체험·견학" / sub 카테고리 / area "경기 남양주시"
```

`area`는 반드시 `경기 남양주시`처럼 **`시도 시군` 꼴**이라야 한다. `남양주시`로 적으면
공백이 없어 화면의 지역 필터가 서울 자치구로 분류해버린다.

**중복 제거를 안 거친다.** 서울 예약과 같은 이유다 — 같은 장소에서 여는 여러 프로그램이라
이름이 겹치는 게 정상이고, 지우면 프로그램이 통째로 사라진다.

### 김포시 (두 번째)

```
목록  https://www.gimpo.go.kr/reserve/webEtcResveList.do?key=113&etcProgramSection=EXPERIENCE&pageUnit=100&pageIndex=<쪽>
상세  https://www.gimpo.go.kr/reserve/webEtcResveView.do?key=113&etcProgramSection=EXPERIENCE&searchEtcResveNo=..
```

코드는 `collect.js`의 `collectGimpo()`. 로그인이 필요 없고 UTF-8인 것은 남양주와 같지만
**화면 구조가 달라 읽는 방법이 다르다.**

**⚠️ 표가 아니라 목록(ul/li)이다.** 남양주처럼 `<tr>`·`<td>`로 자를 수 없다.
항목 하나가 `<li class="participation_item">`으로 시작해서, 이 낱말로 잘라 조각을 만든다.

```html
<li class="participation_item">
  <div class="participation_title">
    <span class="participation_label type2">접수중</span>
    <a href="./webEtcResveView.do?…"><strong>제목</strong></a>
  </div>
  <div class="participation_image"><img src="/DATA/ETC/…png" /></div>
  <div class="participation_information"><ul>
    <li class="participation_information_item"><span class="…_subject">대상</span>제한없음</li>
    …
```

**⚠️ 라벨과 값이 태그로만 나뉘어 있고 사이에 공백이 없다.** `<span>대상</span>제한없음`이라
태그를 걷어내면 `대상제한없음`처럼 붙는다. 그래서 `대상`·`장소`·`신청`·`행사`·`문의`를
**머리글자로 떼어낸다**(`GIMPO_LABELS`). 라벨이 더 생길 수 있으니 아는 것만 처리하고
모르는 줄은 버린다.

**`pageUnit`을 반드시 100으로 올린다.** 기본값이 10이라 그냥 열면 첫 쪽 10건만 보인다.
100으로 올리면 88건이 한 쪽에 다 온다. 코드는 넉넉히 4쪽까지 돌되 항목이 안 나오면 멈춘다.

**상태 배지는 글자로 판단한다.** 클래스는 `participation_label`(대기중) /
`type2`(접수중) / `type3`(마감)인데, 실제 글자는 `접수중` / `완료`다.
클래스 이름은 바뀔 수 있으니 `접수중`이라는 글자를 본다. **88건 중 17건이다.**

**상세를 열지 않는다.** 목록 한 줄에 대상·장소·신청·행사·문의가 다 들어 있어서
남양주와 달리 상세 요청이 필요 없다. 그만큼 빠르다.

| 목록 라벨 | 쓸 곳 |
|---|---|
| 대상 | `target` (**원문 그대로**) + `ageRange()`로 `ageMin`/`ageMax` |
| 장소 | `place` (17건 중 5건만 있다. 나머지는 비운다) |
| 신청 | `rcptStart` ~ `rcptEnd` |
| 행사 | **`start` ~ `end`** |
| 문의 | `tel` |

**★ 행사 날짜가 목록에 있다 — 이게 김포의 강점이다.** 남양주는 접수기간만 있어
날짜 필터에 안 걸렸는데, 김포는 실제 진행 날짜(`start`/`end`)가 목록에 그대로 있다.
이 앱은 날짜로 찾는 앱이라 이게 핵심이다. 17건 전부 채워진다.

**사진도 100% 붙는다.** `src`가 `/DATA/ETC/…`로 시작하는 상대 주소라
앞에 `https://www.gimpo.go.kr`를 붙인다. 상세 링크는 `./`를 떼고
앞에 `https://www.gimpo.go.kr/reserve/`를 붙인다(`&amp;`는 `unent()`로 되돌린다).

**좌표를 시청으로 둔 사정** — 목록이 좌표를 전혀 주지 않는다. `장소` 값에 주소가
섞여 있는 항목이 있지만(`… 경기도 김포시 고촌읍 장차로 14`) **지오코딩은 인증키가 필요해서
하지 않았다.** 그래서 전부 **김포시청**(`37.6152, 126.7157`)으로 간다. 지도 링크는
제목으로도 검색되니 카드가 엉뚱한 지역으로 새지는 않는다. 나중에 남양주(`NYJ_ORG_XY`)처럼
기관별 표로 정교화할 수 있다.

**상시 접수 `9999-01-01`** — 남양주에서 겪은 것과 같은 처리를 `gimpoTerm()`에 넣어뒀다.
지금 김포 자료에는 그런 값이 없지만, 오면 마감 없음으로 본다.

**이번은 견학·체험(`EXPERIENCE`) 하나만이다.** 김포에는 `webEdcLctreList.do` 같은
다른 계열 주소가 있지만 확인 전에는 붙이지 않는다.

서버가 그려주는 목록(`selectGuriUserCourseList.do`)은 **성인 강좌 15건뿐**이고,
곤충생태관·장자호수생태체험관 같은 아이 체험은 `selectWebEdcList.do` 쪽인데
**자바스크립트로만 그려져서 `curl`로는 받을 수 없다.**

### 다른 시군을 붙이려면

같은 꼴로 하나씩 늘려갈 예정이다. 시군 하나 추가는 대략 이 순서다.

1. **그 시군 예약 페이지를 브라우저에서 열어 로그인 없이 목록이 보이는지 본다.**
   보이면 `curl`로 받아 표가 HTML 안에 들어 있는지 확인한다(자바스크립트로 나중에
   그리는 곳이면 이 방식이 안 통한다). 인코딩이 EUC-KR이면 변환이 더 필요하다
2. **표(table)인지 목록(ul/li)인지부터 본다.** 남양주는 표, 김포는 목록이라 자르는 방법이
   아예 달랐다. 그다음 칸 순서와 접수상태 낱말을 확인한다. 시군마다 다르다
3. `collectNamyangju()`(표) 또는 `collectGimpo()`(목록) 중 닮은 쪽을 본떠
   `collect<시군>()`을 만든다. 공통 도구
   (`getText`·`stripTags`·`nyjField`·`toDate`·`ageRange`)는 그대로 쓸 수 있다
4. 기관별 좌표를 TourAPI나 지도에서 찾아 표로 박고, 못 찾은 곳은 시청 좌표를 기본값으로 둔다
5. 실행부에 `const xx = await collect<시군>().catch(...)` 한 줄을 넣고
   `[...merged, ...seoul, ...nyj, ...gimpo, ...MANUAL]` 자리에 끼워 넣는다.
   **중복 제거(`merged`)에는 넣지 않는다**
6. `node --check collect.js` → `node collect.js` → preview.html 다시 만들기 → README 갱신

시군 설정을 배열로 빼는 범용 틀은 **일부러 안 만들었다.** 시군마다 표 모양이 달라
공통 틀이 오히려 방해가 될 가능성이 커서, 두세 곳을 더 붙여보고 진짜 같은 부분이
드러나면 그때 묶는 게 낫다.

## 화면

- 탭 3개: 찾기 / 휴양림 / 설정
- **찾기**: 직접 그린 달력(일=빨강, 토=파랑) + 나이 묶음 체크박스(유아·초등학생 기본 켜짐)
- **지역 필터**: 시도별 체크박스(건수 많은 순, 라벨에 건수 표시). 목록은 코드에 박지 않고
  `DATA`에서 뽑는다 — 자료가 바뀌면 따라 바뀐다. 기본 전부 켜짐, 다 끄면 가리지 않는다
- **요금 필터**: 무료 / 유료 / 요금 미상. `fee`가 비면 미상, `무료`거나 숫자가 0뿐이면 무료,
  나머지는 유료. 기본 전부 켜짐, 다 끄면 가리지 않는다
- 지역·요금 선택은 출발지와 같은 `localStorage` 키(`wg_set`)에 저장한다.
  예전 저장값처럼 그 항목이 없으면 전부 켜진 것으로 본다
- 결과: **섹션(행사·축제 / 예약해야 하는 곳 / 아무 때나 가도 되는 곳 / 직접 확인)** 안에서
  다시 **지역별로 접기·펼치기**. 섹션마다 가장 가까운 지역 하나만 펴짐
- 카드: 사진(152px, 왼쪽) / 1줄 지역·장소 / 2줄 대상 / 제목 / 시간 / 배지 / 링크
- **링크는 두 종류**: `자세히 →`(`url`이 있을 때만)와 `지도 →`(좌표만 있으면 항상, 네이버
  지도 검색 주소를 제목·좌표로 화면에서 만든다). 둘 다 없을 때만 `링크 없음`이 뜬다
- 글자 크기는 카드 안 전부 16px로 통일
- 정렬은 설정의 출발지 기준 **거리순**이되 카드에 km은 표시하지 않는다
- **개수 상한은 없다.** 예전에는 상시 시설을 가까운 40곳(뒤에 500곳)까지만 보여줬는데,
  자료가 614건에서 1,719건으로 늘면서 1,219곳이 아예 안 보이는 상태가 됐다.
  상한으로 자르는 대신 **위의 지역·요금·나이 체크로 사용자가 직접 좁히게** 바꿨다.
  카드가 많아도 사진은 `loading=lazy`라 화면에 들어올 때만 받는다

### 휴양림 탭

숲나들e 휴양림 96곳을 그냥 목록으로 보여준다. **찾기 탭이 아니라 별도 탭인 이유**는,
휴양림이 "아무 때나 가도 되는 곳" 안에 묻혀 있어(거리순 209번째, 지역 묶음 130개 중
13번째) 사실상 찾을 수가 없었기 때문이다. 찾기 탭에서 빼지는 않았다 — 거기도 그대로 있다.

- 자료는 `data.json`의 `forests` 키다. `collect.js`의 `FOREST` 상수를 그대로 내보낸 것으로
  각 항목이 `{region, city, name, id}`. 거르지도 정렬하지도 않고 담긴 순서대로 그린다
- 권역 4개(수도권 25 / 강원 31 / 충북 22 / 대전·충남 18)를 **찾기 탭의 지역 묶음과
  같은 마크업**(`details.zone` + 화살표 + 개수)으로 접었다 편다. **수도권만 펴져 있다**
- 권역 안은 시군별 소제목(14px) 아래 한 줄짜리 링크 목록. 카드가 아니다 — 96곳이라
  촘촘해야 훑기 좋다. 링크는 `indvz/main.do?hmpgId=<id>`
- **찾기 탭의 필터(날짜·나이·지역·요금)는 여기 안 걸린다.** 그냥 목록이다
- 전국 170곳 중 반경 안 네 권역만이라는 것을 맨 위 안내 줄에 적어뒀다

## 지역 이름 통일

서울 예약은 `도봉구`, 표준데이터는 주소에서 뽑아 `서울특별시 도봉구`가 되어 같은 곳이 두 묶음으로
갈렸다. `collect.js`의 `areaOf()`에서 맞춘다 — 서울은 구 이름만, 나머지는 `경기 고양시`처럼 줄인다.

TourAPI는 주소 칸 이름이 달라서(`addr1`), 주소 문자열만 받는 `areaOfAddr()`을 속살로 빼고
`areaOf()`가 그것을 부르게 했다. 규칙은 하나뿐이라 두 자료가 항상 같은 이름으로 나온다.

`SIDO` 표에 없던 시도가 남아 `경상북도 문경시`·`대구광역시 군위군`처럼 안 줄어든 값이 있었다.
경북·경남·대구·부산·울산·광주·전남·제주·세종특별시를 표에 넣었다. 또 `강원특별자치도양구군 양구읍`처럼
**시도와 시군구가 붙은 주소**가 있어, 공백으로 자르기 전에 첫 토막이 아는 시도 이름으로 시작하는지
보고 갈라낸다(긴 이름부터 검사해야 `강원특별자치도`가 `강원도`보다 먼저 걸린다).

시도별 건수 — 서울 892 / 경기 579 / 강원 311 / 충남 249 / 충북 205 / 인천 111 /
대전 55 / 경북 46 / 세종 8 / 대구 4.

## 안 되는 것 (확인 완료, 다시 찾지 말 것)

- **모집정원·잔여석**: 어느 API에도 없다. 서울은 상세설명 글 속에 9%만 있고 그나마 "회차당 1기관"
  같은 형태다. 공연행사 `seatNumber`는 공연장 좌석수지 남은 자리가 아니다
- **숲나들e 실시간 빈자리**: 로그인이 필요해 배포판에 못 넣는다. 산림청 공개 API는
  2023~2024년 과거 통계라 쓸 수 없다. 쓰려면 k-skill(`foresttrip-vacancy`) + 파이썬·Playwright,
  사장님 PC 전용
- **대한민국구석구석 소개 페이지를 contentid로 만들기**: 안 된다. 구석구석의 `cotid`는
  TourAPI의 `contentid`와 **다른 번호 체계**다. `ms_detail.do?cotid=<contentid>`로 만들면
  "찾을 수 없거나 비정상적인 접근" 화면이 뜬다. 게다가 **그 오류 화면도 HTTP 200으로 응답**해서
  상태 코드만 보면 성공처럼 보인다(실제로 1,029건을 죽은 링크로 만들었다가 걷어냈다).
  진짜 홈페이지가 필요하면 `detailCommon2`를 **항목당 한 번씩** 불러야 한다 —
  표본 40건 중 78%가 홈페이지를 갖고 있었지만, 1,029번 호출은 개발계정 하루 한도(1,000회)를
  넘는다. 사용자 결정으로 **지도 링크만 쓰기로 했다.**
- **로그인 벽이 있는 지자체 예약처**: 자동 수집 불가. `collect.js`의 `MANUAL` 목록에
  링크만 넣어 "직접 확인" 칸으로 보여준다. 발견하면 여기 추가.
  ⚠️ 남양주시는 여기 있었지만 **로그인이 필요 없다는 걸 확인해 자동 수집으로 옮겼다**
  (위 "경기도 시군 예약"). 예전에 걸어둔 주소가 내 예약 조회 페이지라 로그인해야 보였던 것이다.
  **`MANUAL`은 지금 빈 배열이고, 화면은 항목 없는 섹션을 알아서 건너뛴다.**
  다른 예약처를 넣을 자리로 남겨뒀다
