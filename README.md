날짜를 고르면 그날 아이와 갈 수 있는 곳을 지역별로 보여주는 개인용 웹페이지.
서울에서 차로 2시간(약 150km) 반경까지. 지인들과 링크로 나눠 쓸 목적.

## 파일

```
index.html          화면 (data.json을 읽는다)
collect.js          자료 수집기 — 거르는 규칙이 전부 여기 있다
sigun/              경기도 시군 예약 (시군 하나에 파일 하나, 지침.md 참고)
data.json           수집 결과 (1,513건 + 휴양림 96곳)
keys.json           인증키 (.gitignore에 있음, 절대 커밋 금지)
keys.example.json   키 넣는 자리 견본
```

미리보기가 필요하면 — `index.html`의 `<script>` 앞에 `window.__DATA__`로 data.json을
끼워 넣어 임시 파일을 만들고, 보고 나면 지운다. 자료가 박힌 사본을 남겨두면 data.json을
고쳐도 안 바뀌어 헷갈린다(예전에 1MB짜리 옛 사본이 남아 있었다).

### 화면은 GitHub Pages, 함수만 Firebase

키즈카페 남은 자리를 세는 중계 함수 하나만 Firebase에 있다(`functions/`). **화면을 옮긴 게
아니다** — 화면은 지금도 GitHub Pages이고 배포는 `git push` 그대로다.

**2026-08-20에 배포를 마쳤다.** 함수 `slots` 하나가 서울 리전에서 돌고 있다.

```
cd functions && npm install          # 처음 한 번 (안 하면 배포가 멈춴다)
firebase.cmd deploy --only functions --project weekend-go-1 --account anthem82@gmail.com
```

- **PowerShell에서는 `firebase`가 아니라 `firebase.cmd`로 부른다.** 실행 정책이
  Restricted라 npm이 까는 `firebase.ps1`이 막힌다(`UnauthorizedAccess` 보안 오류).
  `.cmd`를 직접 지정하면 시스템 설정을 안 건드리고 그냥 된다.
- 프로젝트 `weekend-go-1`은 **이 앱 전용**이고 다모인 프로젝트(nswf301 계정)와 별개다.
  계정이 다르므로 `firebase login:add`로 하나 더 등록해두고 `--account`로 골라 쓴다.
  로그인은 **명령을 돌리는 그 PC에서** 해야 한다(다른 PC에서 하면 그 PC에만 저장된다).
- 빌드 이미지 3일 자동삭제 정책을 켜두었다 — 안 켜면 이미지가 쌓여 매달 몇백 원씩 나온다.

> ⚠️ **함수 안에서 날짜·요일을 다룰 땐 시간대에 기대지 말 것.** Firebase 서버는 UTC다.
> 2026-08-20에 `dayNoOf`가 `+09:00` + `getDay()`를 써서 토요일이 금요일로 하루 밀렸고,
> 요일이 안 맞으니 회차가 0개로 와 늘 "자리 없음"이 됐다. 사용자 PC(한국 시간)에서는
> 멀줦해서 시험을 통과했다. 지금은 `getUTCDay()`로 고정해 센다.
- 함수가 필요한 이유는 하나뿐이다 — 우리동네키움포털이 **다른 사이트에서 온 요청을 막아서**
  (CORS) 화면이 직접 못 묻는다. 서버끼리는 막히지 않으므로 함수가 대신 묻는다.
- 함수가 죽어도 화면은 산다. 목록과 예약 링크는 그대로 나오고 숫자만 안 보인다.

- `keys.json`은 `.gitignore`에 있어 공개 저장소에 올라가지 않는다 (확인 완료).
- `gh`는 `C:\Users\seong\tools\bin\gh.exe` (winget이 없는 LTSC라 zip으로 설치).

### 자연휴양림에 숲나들e 링크 붙이기

휴양림 카드에는 `지도 →`밖에 없어서, 예약 정보를 보려면 숲나들e에 들어가 이름으로
다시 찾아야 했다. 이제 이름이 맞는 휴양림에는 `자세히 →`가 붙어 소개 페이지로 바로 간다.

```
https://www.foresttrip.go.kr/indvz/main.do?hmpgId=<ID>
```

**목록을 어디서 받았나** — 숲나들e 휴양림 검색 목록을 세 단계로 받았다. 세션 쿠키와
CSRF 토큰이 있어야 해서 주소만 안다고 바로 되지는 않는다.

```bash
# 1) 검색 화면을 쿠키와 함께 받아 CSRF 토큰을 뽑는다
curl -s -c ck.txt -A "Mozilla/5.0" \
  "https://www.foresttrip.go.kr/pot/is/fs/selectFcltSrchView.do?hmpgId=FRIP&menuId=002001" -o ft.html
TOKEN=$(grep -oE '_csrf=[0-9a-f-]{36}' ft.html | head -1 | cut -d= -f2)

# 2) 같은 세션으로 권역별 목록을 받는다 (GET, X-Ajax-call 헤더가 필요하다)
curl -s -b ck.txt -A "Mozilla/5.0" -H "X-Ajax-call: true" \
  "https://www.foresttrip.go.kr/rep/or/selectInsttListForSearch.do?_csrf=$TOKEN&srchSido=1"
```

- 권역 코드는 `/rep/or/selectSiDoList.do` 로 얻는다 — **1** 서울·인천·경기, **2** 강원,
  **3** 충북, **4** 대전·충남 (5 전북, 6 전남광주 등은 반경 밖이라 안 받았다)
- `srchSido`를 비우면 빈 목록이 온다. 반드시 권역을 지정해야 한다
- 응답 `insttList[]`에서 쓸 것은 `insttNm`(이름)과 `insttId`(ID) 둘뿐이다.
  나머지 80여 개 칸(`cvncFcl` 편의시설 등)은 **목록 조회에서는 전부 비어 있다**

네 권역을 합쳐 96곳. 받은 날은 2026-08-13. 결과 96줄을 `collect.js`의 `FOREST` 상수에 박아뒀다.
한 줄은 `[권역, 시군, 이름, ID]` — 권역·시군은 화면의 휴양림 탭에서 쓰려고 넣었고,
`data.json`의 `forests` 키로 그대로 나간다. 링크 붙이기(`forestNorm`)는 예전처럼 **이름만** 본다.
**수집기에서 매번 부르지 않는다** — CSRF 토큰과 세션이 필요해 수집기가 복잡해지는 데다,
휴양림 목록 자체는 자주 바뀌지 않는다. 갱신이 필요하면 위 주소를 브라우저에서 다시 불러
받은 목록을 `FOREST`에 덮어쓰면 된다.

**이름 맞추는 규칙** (`forestNorm`) — 양쪽 이름을 같은 꼴로 만들어 비교한다.

- 괄호와 그 안의 글자를 지운다 (`(가평군)강씨봉자연휴양림` → `강씨봉자연휴양림`)
- 공백·`·`·`-`·`_`·`,`·`.`을 지운다
- 맨 앞의 `국립`·`도립`·`시립`·`군립`·`공립`을 지운다 (`국립 산음자연휴양림` → `산음자연휴양림`)
- `자연휴양림`을 `휴양림`으로 통일한다

붙이는 대상은 **TourAPI 관광지(contentTypeId=12)** 중 cat3가 자연휴양림(`A01010600`)이거나
제목에 `휴양림`이 든 것뿐이다. 이미 `url`이 있으면 덮어쓰지 않는다.

**산림욕장·도시자연공원에는 안 붙는다.** 숲나들e는 숙박 예약을 받는 휴양림 통합예약처라
`구름산 산림욕장`·`문수산산림욕장`·`잣향기푸른숲` 같은 곳은 애초에 등록되어 있지 않다.
없는 것을 억지로 검색 링크로 만들지 않는다 — 지도 링크가 그대로 남는다.

결과 — 휴양림성 항목 67건 중 **33건**에 링크가 붙었다. 표본 7건을 실제로 열어
`<title>`에 그 휴양림 이름이 들어 있는 것을 확인했다(구석구석 때처럼 죽은 링크가
아닌지 확인한 것이다).

⚠️ `용현자연휴양림`·`장태산휴양림` 2건은 이름은 맞는데 링크가 없다. **전국관광지정보**
쪽에서 들어온 항목이라 TourAPI 관광지 매핑을 안 거치기 때문이다. 필요하면 그때 넓히면 된다.

### 중복 제거

같은 곳이 여러 자료원에 들어 있다. 이름에서 **괄호와 그 안의 글자를 지우고 → 공백·`·`·`-`·`_`·
`,`·`.`을 지우고 → 소문자로** 바꿔 비교해, 겹치면 하나만 남긴다. 이번엔 236건이 빠졌다.

우선순위는 **TourAPI → 표준데이터(박물관·축제·공연행사) → 전국관광지정보**.
TourAPI를 앞에 둔 것은 사진이 붙어 있어 카드가 잘 보이기 때문이다.

**서울 예약 자료는 중복 제거 대상이 아니다.** 같은 장소에서 여는 여러 프로그램이라
이름이 겹치는 게 정상이고, 지우면 프로그램이 통째로 사라진다.

### 긴 글 자르기

전국관광지정보의 소개글(`trrsrtIntrcn`)은 몇백 자짜리라 **120자에서 자른다**.
안 자르면 data.json이 몇 배로 불어난다.

## 경기도 시군 예약

"예약해야 하는 곳" 칸은 오랫동안 서울시 자료뿐이라 경기도가 0건이었다. 그 구멍을
시군 통합예약포털로 메운다. API가 아니라 **서버가 그려주는 HTML을 읽는다.**

### 시군 하나에 파일 하나

여러 사람이 동시에 시군을 늘려도 서로 덮어쓰지 않게 `sigun` 폴더로 나눴다.

```
sigun/지침.md      새 시군을 붙이는 방법 (여기에 다 있다)
sigun/남양주.js    표 구조 + 상세 열기
sigun/김포.js      목록 구조 + 상세 안 열기
```

각 파일은 `{ name, area, collect(util) }` 를 내보낸다. `collect.js`가 폴더의 `.js`를
전부 읽어 `collect(util)`을 부르고 결과를 합치므로 **새 시군을 등록할 자리가 따로 없다.**
파일만 놓으면 된다. 앞에 `_`가 붙은 파일은 건너뛴다(나중에 공용 파일을 둘 자리).

**공통 도구는 `util`로 넘겨준다** (`toDate`·`unent`·`ageRange`). 시군 파일이 이걸
복사해 갖지 않게 한 것이다 — 규칙이 두 벌이 되면 한쪽만 고쳐져 어긋난다.

**한 시군이 실패해도 나머지는 산다.** 시군마다 `try/catch`로 감싸서, 실패하면 콘솔에
한 줄 남기고 넘어간다.

### 지금 붙어 있는 곳

| 시군 | 건수 | 구조 |
|---|---|---|
| 안산시 체험·견학 | 17 | 목록(`<li>` 안에 또 `<li>`가 있어 `fnView('RESR_..')`로 자른다). 주소에 `searchRcptStat=I`를 넣어 서버가 접수중만 준다. 반려견놀이터는 뺀다 |
| 김포시 견학·체험 | 16 | 목록(`<li>`). 목록 한 줄에 다 있어 상세를 안 연다. 행사 기간·사진이 있다. **링크에 `rep=1`을 붙여야 상세가 열린다** |
| 부천시 관람·체험 | 16 | 목록. 행사 기간이 없다(운영일이 "8월 12·19·26일" 식으로 흩어져 있다) |
| 수원시 교육·강좌·체험 | 14 | 표(`table.yeyak-t`). `q_rowPerPage=100`이면 한 쪽에 다 온다. 자격증·지도사 과정은 뺀다 |

| 고양시 체험·견학 | 5 | 표. 서버가 `q_resveSttusCode=1002`로 접수중만 걸러준다(전체는 849건·85쪽) |
| 의왕시 체험·캠프 | 4 | 카드 목록. 라벨이 `<span class="em">`으로 붙어 있어 뽑기 쉽다 |

전부 로그인이 필요 없고 UTF-8이다. **접수중인 것만 남긴다** — 남양주는 104건 중 7건,
김포는 88건 중 16건이다. 서울 예약이 `접수중·안내중`만 받는 것과 같은 기준이고,
돌릴 때마다 건수가 달라지는 게 정상이다. **중복 제거는 거치지 않는다** — 같은 장소에서
여는 여러 프로그램이라 이름이 겹치는 게 정상이고, 지우면 프로그램이 통째로 사라진다.

**단체 전용은 `collect.js`의 `soloOK()`가 모든 시군에 일괄로 거른다.** 시군 파일에서
같은 규칙을 또 만들지 마라. `target`만 원문 그대로 채워두면 걸린다.

### 붙이지 않은 곳

| 시군 | 왜 |
|---|---|
| 안양 | 목록이 아니라 **시설 하나의 달력**이다. 26건 중 16건이 `안양그린마루 전시해설`의 회차 반복이고 2.4MB를 매번 받아야 한다. `sigun/_안양.js`로 남겨뒀다 — 앞의 `_`를 떼면 되살아난다 |
| 연천 | 서버가 그려주는 목록은 **성인 목공 강좌 33건**뿐이다. 상세를 열어보니 대상이 전부 `고등학생,성인`이었다. 체험마을들은 외부 사이트로 나가는 링크라 이 포털로 신청할 수 없다 |
| 구리·시흥 | 체험/견학 탭 목록을 **자바스크립트로만 그린다.** 브라우저 없이는 못 받는다 |
| 양주 | 통합예약이 교육강좌·시설대관·나리농원 셋뿐이다. 접수중 20건이 자격증 야간과정·현미쌀 요리·창업컨설팅 같은 **성인 강좌**뿐이고 `rcritTrget=child`는 0건이다 |
| 용인 | 붙여봤더니 33건 중 20건이 **농촌테마파크 체험 메뉴판**을 한 줄씩 올린 것이라 한 시설이 목록을 덮었다. 사용자가 제외 결정. 목록은 `resve.yongin.go.kr`의 `BD_selectResveManageList.do`이고 `q_resveCl=CL_01_1`(문화)·`CL_01_2`(안전)에만 자료가 있다 |
| 성남·의정부·포천 | 사용자가 "원하는 정보 없음"으로 판단 |
| 과천 | 프로그램 항목 자체가 없다 |

**시군을 붙일 때는 링크를 반드시 열어서 내용까지 확인할 것.** 김포는 목록 링크에
`rep=1`이 빠져 있어 상세가 "처리중 예외상황이 발생하였습니다" 안내창만 떴다. 주소가
200으로 와도 알맹이가 없을 수 있으니 **제목과 본문 길이까지** 봐야 한다.

`area`는 반드시 `경기 남양주시`처럼 **`시도 시군` 꼴**이라야 한다. 공백이 없으면
화면의 지역 필터가 서울 자치구로 분류해버린다. `kind:"reserve"`면 화면이 알아서
"예약해야 하는 곳"에 넣으므로 `index.html`은 손댈 일이 없다.

구체적인 파싱 방법·좌표를 박은 사정·겪은 함정은 **각 시군 파일 맨 위 주석**에 적어뒀다.

### 구리·시흥은 왜 안 붙였나

구리는 서버가 그려주는 목록(`selectGuriUserCourseList.do`)이 **성인 강좌 15건뿐**이고,
곤충생태관·장자호수생태체험관 같은 아이 체험은 `selectWebEdcList.do` 쪽인데
**자바스크립트로만 그려져서 `curl`로는 받을 수 없다.** 시흥도 같은 이유다.

### 다른 시군을 붙이려면

**`sigun/지침.md`를 보라.** 그 문서 하나만 읽고 시군 하나를 붙일 수 있게 써뒀다 —
어느 탭을 쓰는지(체험견학만 쓴다), 붙일 수 있는지 `curl`로 판별하는 법, 파일 모양과
스키마, 거르는 규칙, 실제로 겪은 함정, 검증 절차, 남양주·김포 두 본보기의 대비까지.

시군 설정을 배열로 빼는 범용 틀은 **일부러 안 만들었다.** 시군마다 화면이 달라
공통 틀이 오히려 방해가 될 가능성이 커서, 몇 곳을 더 붙여보고 진짜 같은 부분이
드러나면 그때 묶는 게 낫다.

## 나이 읽기 (핵심)

대상 문구를 **자르지 않고 통째로** 읽어 나이 범위를 뽑는다. 495건 100% 해석됨.

```
"유아(만5세이상), 초등학생"             → 5~12세
"가족(초등학교 4~6학년 어린이 동반 가족)" → 10~12세
"성인, 청소년, 초등학생(4학년이상)"      → 10~99세
```

방식: 괄호를 지키며 쉼표로 나눔 → 조각마다 낱말로 기본 범위(유아=3~6) → 괄호 안 나이·학년으로 **교집합**.
카드에는 대상 **원문 그대로** 보여준다. 잘라 쓰면 안 된다(사용자 지시).

## 화면

- 탭 4개: 찾기 / 휴양림 / 키즈카페 / 설정
- **찾기**: 직접 그린 달력(일=빨강, 토=파랑) + 나이 묶음 체크박스(유아·초등학생 기본 켜짐)
- **소제목 넷은 묻는 말**이다 — `언제 갈까? / 누가 갈까? / 어디로 갈까? / 얼마면 되니?`.
  앞에 손그림 선 아이콘을 붙였다. 이모지가 아니라 파일 안에 그린 SVG라 기기마다
  다르게 보이지 않는다(팔레트가 PostHog 계열이라 검은 선 + 크림·주황 면으로 맞췄다)
- **지역 필터**: **권역** 체크박스 — 서울 / 경기·인천 / 강원 / 충청권 / 전라권 / 경상권.
  이 여섯은 자료가 0건이어도 늘 보여준다(자리가 고정돼야 어디가 빈지 안다). 제주와
  분류 밖 지역은 자료가 있을 때만 붙는다. 기본 전부 켜짐, 다 끄면 가리지 않는다.
  ⚠️ 예전에는 시도(충북·충남)로 저장했다. 그 저장값이 남아 있으면 권역 이름과 하나도
  안 맞아 목록이 통째로 비므로, 겹치는 게 없으면 저장값을 버리고 전부 켠다
- **요금 필터**: 무료 / 유료 / 요금 미상. `fee`가 비면 미상, `무료`거나 숫자가 0뿐이면 무료,
  나머지는 유료. 기본 전부 켜짐, 다 끄면 가리지 않는다
- 지역·요금 선택은 출발지와 같은 `localStorage` 키(`wg_set`)에 저장한다.
  예전 저장값처럼 그 항목이 없으면 전부 켜진 것으로 본다
- 결과: **섹션(행사·축제 / 예약해야 하는 곳 / 아무 때나 가도 되는 곳 / 직접 확인) →
  권역 → 시군구** 3단으로 접힌다. 한 권역이 **40곳을 넘을 때만** 시군구도 접고,
  그보다 적으면 시군구는 소제목으로 펼쳐 둔다(두세 곳짜리까지 접으면 누를 것만 는다).
  **처음에는 아무것도 펴지 않는다** — 섹션 제목 셋만 보이고 누르는 만큼 열린다.
  ⚠️ 예전에는 시군구 113개가 한 줄씩 늘어서서 제목만 화면을 채웠다. 그래서 권역으로 묶었다
- 카드: 사진(152px, 왼쪽) / 1줄 지역·장소 / 2줄 대상 / 제목 / 시간 / 배지 / 버튼
- **배지는 상태·요금·주차뿐이다.** 분류(교육체험·전시/관람·테마공원 …)는 달지 않는다 —
  제목을 읽으면 아는 내용이라 배지 줄만 길어졌다. 되살리려면 `badges()`에 sub/group을 넣는다
- **버튼 두 개**: `자세히`(`url`이 있을 때만)와 `지도`(좌표만 있으면 항상, 네이버 지도 검색
  주소를 제목·좌표로 화면에서 만든다). 둘 다 없을 때만 `링크 없음`이 뜬다
- **버튼은 색이 셋이다** — 채움 `--btn-face` / 턱 `--btn-lip` / 아웃라인 `--btn-line`.
  아웃라인이 채움과 턱을 통째로 감싼다(그림자를 두 겹 겹쳐 만든다: 앞이 턱의 몸통,
  뒤를 2px 넓혀 그려 턱의 테두리). posthog.com 버튼을 확대해서 맞춘 것이라 임의로
  단색으로 바꾸지 말 것 — 셋이 같으면 납작해 보인다. 흰 버튼(지도)의 턱만 `--btn-lip-2`
- 글자 크기는 카드 안 전부 16px로 통일
- 정렬은 설정의 출발지 기준 **거리순**이되 카드에 km은 표시하지 않는다
- **개수 상한은 없다.** 예전에는 상시 시설을 가까운 40곳(뒤에 500곳)까지만 보여줬는데,
  자료가 614건에서 1,719건으로 늘면서 1,219곳이 아예 안 보이는 상태가 됐다.
  상한으로 자르는 대신 **위의 지역·요금·나이 체크로 사용자가 직접 좁히게** 바꿨다.
  카드가 많아도 사진은 `loading=lazy`라 화면에 들어올 때만 받는다

### 키즈카페 탭

서울형 키즈카페 133곳(25개 자치구). **찾기 목록에는 넣지 않는다** — 지점마다 줄이 생겨
다른 곳을 덮는다. 그래서 `collect.js`가 서울 예약을 훑을 때 `KIDSCAFE`로 따로 빼내
`data.json`의 `kidscafe` 키에 담고, 이 탭에서만 그린다(찾기 목록에는 0건).

- **날짜를 고르면 남은 자리를 그 자리에서 센다.** 숫자를 `data.json`에 담아두지 않는 이유는
  수시로 바뀌기 때문이다 — 하루 지난 "11자리 남음"은 헛걸음을 만든다
- 자리를 세는 통로는 우리동네키움포털의 `ND_selectResveTmeList.do`다. 로그인이 필요 없다.
  다만 **화면이 직접 부르면 브라우저가 막아서**(CORS) Firebase 함수를 거친다(`functions/`)
- 함수가 죽어도 화면은 산다 — 안내 한 줄과 함께 목록·예약 링크는 그대로 나온다
- 확인한 규칙: `q_dayNo`는 일=1 … 토=7(날짜와 안 맞으면 회차 0개), 휴관일은 회차가 오되
  시각이 `null`, 남은 자리 = `resvePsncpa - resveNmpr`, 괄호의 돌봄 자리는 따로 온다
- 한 건(송파 한성백제박물관점)만 우리동네키움포털이 아니라 서울시 공공서비스예약으로
  연결된다. 시설 ID가 없어 자리 세기에서는 빠지고 목록에만 보인다(132/133곳)

**화면은 회차별로 보여준다**(2026-08-20). 한 회차가 한 줄이다 — `1회차 공용 09:10~11:00 20명`.

- **합계 자리수는 적지 않는다.** 지점 이름 옆과 구 제목 옆에 있던 `68자리`를 뻐다 —
  쓸 데가 없고 회차별 인원이 가려졌다. 자리가 없는 곳에만 "자리 없음"을 붙인다
- 마감된 회차는 줄 전체를 흐리게(`.kid-slot.zero`), 글자는 14px가 아니라 **16px**이다
- 관공서 표에 있는 `돌봄가능` 숫자는 **안 보여준다**(사용자 결정). 함수는 `care`로
  계속 보내고 있으니 필요해지면 화면에서 꺼내 쓰면 된다
- 지점 링크에 고른 날짜의 **연·월을 붙인다**(`q_year`·`q_month`) — 예약 달력이 그 달로 열린다.
  **하루까지는 못 찍는다** — `q_resveDe`를 주소에 붙여도 서버가 무시하고 빈 값으로
  돌려준다. 그 사이트는 화면에서 날짜를 눌렀을 때만 처리한다(2026-08-20 전수 확인).
  다시 파지 말 것

## 지역 이름 통일

서울 예약은 `도봉구`, 표준데이터는 주소에서 뽑아 `서울특별시 도봉구`가 되어 같은 곳이 두 묶음으로
갈렸다. `collect.js`의 `areaOf()`에서 맞춘다 — 서울은 구 이름만, 나머지는 `경기 고양시`처럼 줄인다.

TourAPI는 주소 칸 이름이 달라서(`addr1`), 주소 문자열만 받는 `areaOfAddr()`을 속살로 빼고
`areaOf()`가 그것을 부르게 했다. 규칙은 하나뿐이라 두 자료가 항상 같은 이름으로 나온다.

`SIDO` 표에 없던 시도가 남아 `경상북도 문경시`·`대구광역시 군위군`처럼 안 줄어든 값이 있었다.
경북·경남·대구·부산·울산·광주·전남·제주·세종특별시를 표에 넣었다. 또 `강원특별자치도양구군 양구읍`처럼
**시도와 시군구가 붙은 주소**가 있어, 공백으로 자르기 전에 첫 토막이 아는 시도 이름으로 시작하는지
보고 갈라낸다(긴 이름부터 검사해야 `강원특별자치도`가 `강원도`보다 먼저 걸린다).

시도별 건수 — 서울 892 / 경기 579 / 강원 311 / 충남 249 / 충북 205 / 인천 111 /
대전 55 / 경북 46 / 세종 8 / 대구 4.

## 안 되는 것 (확인 완료, 다시 찾지 말 것)

- **모집정원·잔여석**: 어느 API에도 없다. 서울은 상세설명 글 속에 9%만 있고 그나마 "회차당 1기관"
  같은 형태다. 공연행사 `seatNumber`는 공연장 좌석수지 남은 자리가 아니다
- **숲나들e 실시간 빈자리**: 로그인이 필요해 배포판에 못 넣는다. 산림청 공개 API는
  2023~2024년 과거 통계라 쓸 수 없다. 쓰려면 k-skill(`foresttrip-vacancy`) + 파이썬·Playwright,
  사장님 PC 전용
- **대한민국구석구석 소개 페이지를 contentid로 만들기**: 안 된다. 구석구석의 `cotid`는
  TourAPI의 `contentid`와 **다른 번호 체계**다. `ms_detail.do?cotid=<contentid>`로 만들면
  "찾을 수 없거나 비정상적인 접근" 화면이 뜬다. 게다가 **그 오류 화면도 HTTP 200으로 응답**해서
  상태 코드만 보면 성공처럼 보인다(실제로 1,029건을 죽은 링크로 만들었다가 걷어냈다).
  진짜 홈페이지가 필요하면 `detailCommon2`를 **항목당 한 번씩** 불러야 한다 —
  표본 40건 중 78%가 홈페이지를 갖고 있었지만, 1,029번 호출은 개발계정 하루 한도(1,000회)를
  넘는다. 사용자 결정으로 **지도 링크만 쓰기로 했다.**
- **로그인 벽이 있는 지자체 예약처**: 자동 수집 불가. `collect.js`의 `MANUAL` 목록에
  링크만 넣어 "직접 확인" 칸으로 보여준다. 발견하면 여기 추가.
  ⚠️ 남양주시는 여기 있었지만 **로그인이 필요 없다는 걸 확인해 자동 수집으로 옮겼다**
  (위 "경기도 시군 예약"). 예전에 걸어둔 주소가 내 예약 조회 페이지라 로그인해야 보였던 것이다.
  **`MANUAL`은 지금 빈 배열이고, 화면은 항목 없는 섹션을 알아서 건너뛴다.**
  다른 예약처를 넣을 자리로 남겨뒀다
