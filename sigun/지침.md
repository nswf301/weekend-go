# 경기도 시군 예약 붙이기 — 지침

이 문서 하나만 읽고 시군 하나를 붙일 수 있게 썼다. 남양주·김포를 붙이면서 실제로
겪은 것만 적었다.

---

## 1. 목적 — 무엇을 채우는가

이 앱은 **예약을 편하게 하려고** 만들었다. 채우는 칸은 화면의 **"예약해야 하는 곳"**
하나다. 지금 신청할 수 있는 프로그램을 모아 보여주는 것이 전부다.

**장소 목록을 늘리는 작업이 아니다.** 박물관·공원 같은 상시 시설은 이미 다른
자료원(TourAPI·표준데이터)이 채우고 있다. 여기서 붙이는 것은 **신청 기간이 있고
날짜가 정해진 프로그램**뿐이다.

---

## 2. 시군 예약 사이트는 대개 이렇게 생겼다

시군마다 통합예약포털이 하나씩 있고, 보통 이런 탭으로 나뉜다.

| 탭 | 쓰나 | 왜 |
|---|---|---|
| 교육강좌 | **안 쓴다** | 성인 강좌(요가·엑셀·통기타)가 대부분이다. 구리시에서 실제로 열어 확인했다 |
| **체험견학** | **✓ 이것만 쓴다** | 아이·가족 대상 체험·견학 프로그램이 여기 있다 |
| 시설대관 | 안 쓴다 | 강당·체육관 빌리기다. 나들이와 무관하다 |
| 온라인접수 | 안 쓴다 | 민원 접수·설문이 섞여 있다 |

이름은 시군마다 조금씩 다르다(`체험견학` `견학·체험` `체험학습`). **주소의 낱말로도
가늠할 수 있다** — 김포는 `etcProgramSection=EXPERIENCE`가 체험견학이고
`webEdcLctreList.do`가 교육강좌다.

탭을 고른 뒤 **목록에 실제로 뭐가 있는지 눈으로 먼저 본다.** 성인 강좌만 잔뜩이면
그 시군은 안 붙이는 게 맞다.

---

## 3. 붙일 수 있는지 판별 — 이걸 먼저 한다

목록 주소를 `curl`로 받아 **프로그램 제목이 HTML 글자 안에 있는지** 본다.

```
curl -s "https://www.○○.go.kr/reserve/...List.do?..." | grep "실제 프로그램 제목 일부"
```

- **제목이 나온다** → 서버가 HTML을 그려주는 것이다. **붙일 수 있다.**
- **안 나온다** → 브라우저가 자바스크립트로 나중에 그리는 것이다. **이 방식으로는 못 받는다.**

지금까지 확인한 결과다.

| 시군 | 결과 |
|---|---|
| 남양주 | 된다 (표 구조) |
| 김포 | 된다 (목록 구조) |
| 구리 | 안 된다 — 체험 목록이 자바스크립트로만 그려진다 |
| 시흥 | 안 된다 — 같은 이유 |

**안 되면 억지로 파지 마라.** 헤드리스 브라우저를 붙이거나 내부 API를 추측하는 짓은
하지 말고, **그대로 보고하고 멈춰라.** 안 되는 시군이 있는 것은 정상이다.

---

## 4. 파일 모양 — 이 꼴을 지켜라

파일 이름은 **한글 시군명**이다. `sigun/김포.js` `sigun/고양.js`.
(앞에 `_`가 붙은 파일은 `collect.js`가 건너뛴다. 나중에 공용 파일을 둘 자리다.)

```js
module.exports = {
  name: "김포시",
  area: "경기 김포시",      // 다른 자료와 같은 꼴이라야 지역 필터가 맞는다
  async collect(util) {     // util = { toDate, unent, ageRange }
    // ... 목록을 받아 항목 배열을 돌려준다
    return rows;
  },
};
```

**공통 도구는 인자로 받는다.** `collect.js`가 자기 `toDate`·`unent`·`ageRange`를
`util`로 넘겨준다. **시군 파일이 따로 복사해 갖지 마라** — 규칙이 두 벌이 되면
나중에 한쪽만 고쳐져 어긋난다.

| 도구 | 하는 일 |
|---|---|
| `util.toDate(s)` | `"2026-08-14 09:00"` → `"2026-08-14"` |
| `util.unent(s)` | `&amp;` `&#039;` `&nbsp;` 같은 것을 글자로 되돌린다 |
| `util.ageRange(t)` | 대상 문구 → `[최소나이, 최대나이]` 또는 `null` |

`fetch` 하는 함수나 태그 걷어내는 함수처럼 두어 줄짜리는 자기 파일 안에 두면 된다
(남양주·김포 둘 다 그렇게 했다). 다만 **실체참조를 되돌릴 땐 반드시 `util.unent`를 써라.**

`collect.js`는 `sigun` 폴더의 `.js`를 전부 읽어 각각 `collect(util)`을 부르고 결과를
합친다. **한 시군이 실패해도 나머지는 산다** — 시군마다 `try/catch`로 감싸져 있어서
실패하면 콘솔에 한 줄 남기고 넘어간다.

## 5. 항목에서 뽑을 것 (스키마)

| 칸 | 필수 | 설명 |
|---|---|---|
| `kind` | ✓ | 항상 `"reserve"` |
| `group` | ✓ | 항상 `"체험·견학"` |
| `title` | ✓ | 프로그램 이름 |
| `area` | ✓ | `"경기 ○○시"` — 다른 자료와 같은 꼴 |
| `lat`,`lng` | ✓ | 시청 좌표를 공통으로 쓴다 (목록에 좌표가 없다) |
| `url` | ✓ | 상세 링크. 상대주소면 앞을 붙여라 |
| `target` | | 대상 **원문 그대로**. 잘라 쓰지 마라 |
| `ageMin`,`ageMax` | | `util.ageRange(target)` 결과 |
| `start`,`end` | | **행사(진행) 기간** — 이 앱은 날짜로 찾으니 있으면 꼭 채워라 |
| `rcptStart`,`rcptEnd` | | 접수(신청) 기간 |
| `place`,`tel`,`img`,`fee`,`time`,`sub` | | 있으면 |

`area`는 반드시 **`시도 시군` 꼴**이다. `김포시`처럼 공백 없이 적으면 화면의 지역
필터가 서울 자치구로 분류해버린다.

`lat`/`lng`는 **시청 좌표를 공통으로** 쓴다. 목록이 좌표를 주지 않기 때문이다.
지도 링크는 제목으로도 검색되니 카드가 엉뚱한 지역으로 새지는 않는다. 기관 이름이
목록에 나오면 남양주(`ORG_XY`)처럼 기관별 좌표표를 박아도 된다.

값이 없는 칸은 빈 문자열(`""`)이나 `null`로 두면 된다 — `collect.js`가 저장할 때
알아서 뺀다.

## 6. 거르는 규칙 — 접수중만 남긴다

**접수 중인 것만 넣는다. 마감·대기·종료는 전부 버린다.** 서울 자료와 같은 기준이다.

지금 신청할 수 없는 것을 넣으면 "예약해야 하는 곳" 칸이 못 쓰는 카드로 가득 찬다.
남양주는 104건 중 8~9건, 김포는 88건 중 17건만 남는다. **버리는 게 정상이다.**

돌릴 때마다 건수가 달라지는 것도 정상이다 — 접수 상황이 매일 바뀐다.

**중복 제거는 하지 않는다.** 같은 장소에서 여는 여러 프로그램이라 이름이 겹치는 게
정상이고, 지우면 프로그램이 통째로 사라진다. `collect.js`의 중복 제거(`merged`)에
시군 자료는 애초에 들어가지 않는다.

---

## 7. 흔한 함정 — 실제로 겪은 것들

**쪽 나눔을 놓치기 쉽다.** 김포는 첫 쪽만 보면 10건인데 `pageUnit=100`을 주니 88건이었다.
기본값이 10이었던 것이다. **목록 화면의 총 건수 표기를 먼저 확인하고, 그 수만큼
받았는지 맞춰봐라.** 쪽은 끝까지 돌리되 항목이 안 나오면 멈추게 해라.

**상태 배지 글자가 사이트마다 다르다.** 김포는 마감을 `접수마감`이 아니라 `완료`라고
적는다. 클래스 이름도 `type2`(접수중)·`type3`(마감)처럼 뜻이 안 보이고 언제든 바뀐다.
**클래스보다 글자로 판별하는 편이 안전하다.**

**라벨과 값이 태그로만 나뉘어 붙어 있는 경우가 있다.** 김포는
`<span>대상</span>제한없음`이라 태그를 걷어내면 `대상제한없음`이 된다.
**아는 라벨을 머리글자로 떼어내고**(`대상`·`장소`·`신청`·`행사`·`문의`),
모르는 줄은 버려라.

**상시 접수를 `9999-01-01`로 적는 곳이 있다.** 남양주가 그렇다. 그대로 두면 카드에
"접수 마감 9999년 1월 1일"이 뜬다. **마감 없음(빈 문자열)으로 처리해라.**

**`&amp;` `&#039;` `&nbsp;`를 되돌려라.** 특히 상세 링크의 `&amp;`를 그대로 두면
링크가 깨진다. `util.unent()`를 써라.

**인코딩은 대개 UTF-8이지만 아닐 수도 있다.** EUC-KR이면 글자가 깨져 나오니
바로 알아챌 수 있다. 그때는 변환이 더 필요하다.

## 8. 검증 — 여기까지 해야 끝이다

```
node --check sigun/○○.js     문법
node collect.js               실제로 돌린다
```

`node collect.js`를 **실제로 돌려** 이것들을 확인해라.

1. **몇 건 들어왔나** — 콘솔에 `○○시 접수중 N건`이 찍힌다. 0건이면 뭔가 틀린 것이다
2. **`start`·`target`·`ageMin`이 채워진 비율** — 특히 `start`(행사 기간)는 이 앱이
   날짜로 찾는 앱이라 중요하다. 목록에 없으면 0%여도 어쩔 수 없지만, 있는데 0%면 잘못 잡은 것이다
3. **들어온 항목 3건의 제목·대상·기간을 눈으로 본다** — 이게 제일 중요하다.
   성인 강좌(요가·엑셀·자격증)만 잔뜩 들어왔으면 탭을 잘못 고른 것이다

이런 식으로 보면 된다.

```
node -e "const d=require('./data.json');
const x=d.items.filter(i=>i.area==='경기 ○○시');
console.log(x.length, 'start', x.filter(i=>i.start).length, 'target', x.filter(i=>i.target).length);
x.slice(0,3).forEach(i=>console.log('-',i.title,'|',i.target,'|',i.start,'~',i.end));"
```

마지막으로 `preview.html`을 다시 만들어(`index.html`의 `<script>` 앞에
`window.__DATA__`로 `data.json`을 끼워 넣는다) 카드가 제대로 그려지는지 본다.

## 9. 본보기 두 개 — 자기 사이트가 어느 쪽에 가까운지 보라

두 파일이 **왜 다르게 생겼는지**만 알면 된다. 자르는 방법이 아예 다르다.

| | **남양주** (`남양주.js`) | **김포** (`김포.js`) |
|---|---|---|
| 목록 구조 | **표** — `<tr>` 안에 `<td>` 7칸 | **목록** — `<li class="participation_item">` |
| 자르는 법 | `<tr>`로 자르고 `<td>` 순서로 읽는다 | 클래스 낱말로 문자열을 쪼갠다 |
| 값 찾는 법 | **칸 순서**(0 번호 · 1 기관 · 3 제목 · 4 접수기간 · 6 상태) | **라벨 머리글자**(`대상` `장소` `신청` `행사` `문의`) |
| 상세 열기 | **연다.** 목록에 대상·요금·장소가 없다 | **안 연다.** 목록 한 줄에 다 있다 |
| 행사 기간 | **없다.** 접수기간만 있다 | **있다.** 17건 전부 채워진다 |
| 사진 | 없다 | 있다 (100%) |
| 좌표 | 기관별 표(`ORG_XY`) + 시청 기본값 | 시청 하나 |

**어느 쪽을 본떠야 하나**

- 목록이 `<table>`이고 칸이 줄지어 있으면 → **남양주를 본떠라.**
  대상·요금이 목록에 없으면 상세를 열어야 한다. 접수중인 것만 열면 10건 안팎이라
  부담 없다. **상세를 못 받아도 목록 정보만으로 넣고 콘솔에 한 줄 남겨라** —
  시청 페이지 하나 때문에 수집 전체가 죽으면 안 된다.
- 목록이 카드·리스트 모양이고 한 항목에 정보가 몰려 있으면 → **김포를 본떠라.**
  상세를 안 열어도 되니 훨씬 빠르다.

행사 기간(`start`/`end`)이 목록에 있으면 **꼭 챙겨라.** 남양주는 없어서 날짜 필터에
안 걸리고, 김포는 있어서 걸린다. 이 앱에서는 그 차이가 크다.

## 10. 하지 말 것

- **다른 시군 파일을 건드리지 마라.** 여럿이 동시에 붙이는 중이라 충돌한다
- **`collect.js`를 건드리지 마라.** 폴더를 읽어 알아서 합치므로 등록할 필요가 없다
- **`index.html`을 손대지 마라.** `kind:"reserve"`면 화면이 알아서 자리를 잡는다
- **접수마감된 것을 넣지 마라**
- **이모지를 쓰지 마라**
- 쓰지도 않을 범용 틀을 미리 만들지 마라. 시군마다 화면이 달라 공통 틀이 오히려 방해가 된다
